# Smart Traffic Intelligence & Urban Mobility Platform

A geospatial traffic intelligence and urban mobility platform that combines:

- Traffic data
- Weather data
- Incident reports
- Historical traffic analytics
- Machine learning based congestion prediction
- Smart route comparison
- Interactive maps

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- PostgreSQL
- PostGIS

### Machine Learning
- Pandas
- Scikit-learn
- XGBoost

### Maps
- Leaflet / MapLibre
- OpenStreetMap-compatible data
